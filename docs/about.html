About me

A few things that shape the work

I like pages that load fast, read well, and don’t hide the structure. This site is static on purpose: HTML, CSS, and Bootstrap, with no server required.

Background

I’m Bryce. I spend my time making small websites, learning layout systems, and keeping markup honest. I care about accessible defaults, sensible headings, and designs that still work when JavaScript is optional.

When I’m not in a code editor, I’m usually sketching ideas, reading about design systems, or taking apart a page to see why it feels calm.

How I like to work

  • Start with content, then add structure and style.
  • Prefer components I can reuse across pages without a build step.
  • Test on a phone-sized screen before calling anything done.

Focus areas

  • Semantic HTML
  • Responsive Bootstrap layouts
  • Clear writing for the web
  • Static hosting and simple deploys
